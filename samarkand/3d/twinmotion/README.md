# Samarkand R12-v11.7 for Twinmotion

`Samarkand_R12-v11.7.fbx` — whole model, metres, Z up, all textures embedded (owner's carpet photos, wood, marble, plants).

Import: Twinmotion → Import → File → choose the FBX → **Merge: Keep hierarchy**, **Collapse by material: off**, Up axis **Z**,
units **metres**. Then in the material picker drag Twinmotion materials onto:
velvet (curtains, drapes) → Fabric velvet; glazed tiles → Ceramic glossy; brass → Metal brass; LED strips / chandelier
globes → Emissive (warm 2700 K); glass → Glass. Carpets, walnut, marble and brick keep their textures.
