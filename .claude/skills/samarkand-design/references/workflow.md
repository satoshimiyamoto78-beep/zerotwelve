# Рабочий процесс и инструменты

## Этапы
1. **Замеры и инженерия** — план от арендодателя/замер, фото, точки воды, канализации, вытяжки, электрощит.
2. **Концепт** — зонирование на схеме + герои зон + мудборд по палитре.
3. **Планировка** — план расстановки с размерами, таблица посадки, потоки (SVG/DXF).
4. **3D-модель** — SketchUp (заказчик) + Ruby-скрипты от Claude для мебели и элементов.
5. **Визуализация** — D5 Render (Live Sync из SketchUp); быстрый просмотр — three.js-артефакт.
6. **Спецификация** — мебель, отделка, свет, декор, с поставщиками во Вьетнаме.
7. **Рабочая документация** — LayOut / DWG, передача подрядчику.

## SketchUp Ruby — соглашения для скриптов
- Единицы: метры в коде через `.m` (`2.0.m`), все размеры параметрами в начале скрипта.
- Каждый объект — **компонент** (`definitions.add`), экземпляры через `add_instance` — тогда работают спецификации (Generate Report).
- Обёртка `model.start_operation('Samarkand: …', true)` … `commit_operation` — одна отмена Ctrl+Z.
- Теги: `A-Стены`, `A-Ниши`, `F-Мебель`, `F-Тапчаны`, `L-Свет`, `D-Декор`, `T-Текстиль`, `C-Потолок`.
- Материалы: имя `SMK-<токен>` (`SMK-Саман`, `SMK-Орех`, `SMK-Лазурит`), цвет из палитры SKILL.md; текстуры — с реальным размером (`material.texture.size = 0.5.m`).
- Скрипт вставляется в `Window → Ruby Console` (или сохраняется как `.rb` в Plugins). Работает в SketchUp Pro/Make 2017+; в SketchUp Go/Web Ruby нет.

## Текстуры
- Бесшовный тайл, 2048–4096 px, реальный размер в метрах указывается в имени: `ikat-red_0.6m.jpg`.
- Для D5: albedo + normal + roughness.
- Источник узора: генерация (Higgsfield/Nano Banana) → бесшов → апскейл → карты.

## Выдача
- Просмотр на телефоне — опубликованный артефакт (three.js / страница с планом).
- Файлы проекта — `samarkand/` в этом репозитории (коммит в рабочую ветку).

## Местные ресурсы (Дананг / Хойан / Вьетнам)
- **Резьба по дереву**: деревня Ким Бонг (Kim Bồng, Хойан) — резные панели, панджара, колонны (`chạm khắc gỗ`).
- **Фонари**: мастерские шёлковых фонарей Хойана — абажуры из ткани-иката по эскизу (`đèn lồng Hội An`).
- **Цементная плитка**: `gạch bông` — производители делают гирих/звёзды по заказу.
- **Керамика**: Бат Транг (Bát Tràng, Ханой) — плитка, раковины-чаши, посуда по эскизу.
- **Лазерная резка** металла/МДФ (`cắt CNC`) — решётки-гирих в Дананге повсеместно.
- **Дизайн+стройка под ключ** (`thiết kế thi công nhà hàng`) — местные компании, часто дизайн со скидкой при заказе стройки.
- Аутентичные вещи (сюзане, ляганы, риштанская керамика, сандыки) — везти из Узбекистана, заранее, с учётом таможни.
